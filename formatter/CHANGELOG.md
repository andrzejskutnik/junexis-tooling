# Changelog

All notable changes to @junexislang/formatter will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2025-10-31

### Added - Phase 8.2: Comment Preservation

- Comment printing support
- Comment integration for declarations
- Leading and trailing comment handling

## [0.1.0] - 2025-10-26

### Added
- Initial release
- Core `format()` API
- `isFormatted()` utility
- Configuration system
- Error resilience
- Idempotent formatting
